# ACTUARY QUEST 製品仕様

更新日: 2026-08-14

## 1. 製品の狙い

生保数理の過去問を「解説を読むだけ」ではなく、自分で解答し、結果を受け取り、詰まりを残し、再挑戦する学習体験へ変換する。

中心となる原則は次の3つです。

1. 本番問題の難度と正答は変えない。
2. ゲーム要素は学力評価を歪めず、継続する気持ちよさとして加える。
3. 初学者には答えではなく、次に考える一段を渡す。

## 2. 対象コンテンツ

- 年度: 2025年度
- 大問: 問題2

- 公式問題・解答: `public/exam/2025-q2/`

## 3. 通常版 `/`

### 3.1 ロビー

表示内容:

- 2025年度 生保数理 問題2
- BOSS HP 56
- 全8問、目標時間42分、公式56点
- 過去の最高公式得点
- ハイスコア
- 連続学習日数
- 通常演習開始ボタン
- 誘導版への入口

効果音は画面上でON/OFFできますが、現在は再読込後まで保存しません。

### 3.2 問題演習

問題ごとに次を表示します。

- 経過時間と問題別PAR
- BOSS HP
- コンボとバトルスコア
- 公式問題画像と拡大モーダル
- 解法の軸となる任意ヒント
- 問題形式に応じた選択UI

問題形式:

- `single`: 1つ選択
- `dual`: ①と②へ1つずつ選択
- `multi`: 複数選択。Fは「いずれも該当しない」で排他的

### 3.3 採点

公式得点:

- 問1、3〜8: 完全一致で7点、それ以外0点
- 問2: ①Cで3点、②Hで4点

フィードバック:

- 7点: `CRITICAL HIT`
- 1〜6点: `PARTIAL BREAK`
- 0点: `ATTACK BLOCKED`

バトルスコアは公式得点と分離しています。

```text
基本点 = 公式得点 × 100 × コンボ倍率
速解きボーナス = PARの55%以内かつ得点ありなら180
ノーヒントボーナス = ヒント未使用かつ得点ありなら220
獲得バトルスコア = 基本点 + 速解き + ノーヒント
```

コンボ倍率は完全正解の連続数に応じて1.00、1.25、1.50、1.75、最大2.00です。部分点または不正解でコンボは0へ戻ります。

### 3.4 解答後

- 自分の解答と正答を比較
- 公式得点とバトルスコアの内訳
- 公式解答画像
- 詰まった箇所のメモ
- 次の問題への遷移

詰まりメモ:

- 最大500文字
- 問題別に保存
- タグ: 問題文の読み取り、方針・立式、公式の想起、計算、時間配分
- 解答後に過去のメモが復元される
- 結果画面でメモのある問題を一覧表示

### 3.5 結果画面

- 公式得点56点満点
- 残りBOSS HP
- バトルスコア
- 総時間
- 完全正解数
- 最大コンボ
- 問題別ログ
- 次に復習すべき論点
- 詰まりメモ一覧
- 再挑戦

ランク:

- S: 56点
- A: 49点以上
- B: 35点以上
- C: 34点以下

## 4. 誘導版 `/guided`

### 4.1 演習マップ

- 全8問を論点別に一覧表示
- 各問題のステップ数を表示
- クリア済み問題にチェックを表示
- 通常版へ戻る導線

### 4.2 ステップ演習

常に公式問題画像を参照できる状態で、1問を4〜6段へ分けます。

ステップの段階:

- `READ`: 問題文から条件を拾う
- `MODEL`: 方針やモデルを選ぶ
- `DERIVE`: 式を導く
- `CALC`: 計算する
- `JUDGE`: 記述や公式の正誤を判定する

各ステップは次を持ちます。

- タイトル
- 問いかけ
- 任意の数式
- 原則3つの選択肢
- 正答インデックス
- 正答後の短い説明
- 誤答時の限定ヒント

### 4.3 誤答と正答

誤答時:

- `NOT YET`
- 誤答回数
- その場で見直すべき一点
- 同じ選択肢群から再挑戦

正答時:

- `LOGIC ACQUIRED`
- その段の意味
- 次ステップへのボタン

正解を選ぶまで次へ進めません。

### 4.4 理解度

問題開始時は100%。その問題内での誤答1回につき10ポイント下がり、最低40%です。

これは試験得点ではなく、そのセッション内のフィードバック表示です。保存しません。

### 4.5 クリア

- 最終解答
- その問題で通った論理ルート
- 理解度
- 公式解答画像
- 次の問題、演習マップ、通常版への導線

保存するのはクリア済み問題IDのみです。途中ステップ、誤答数、理解度は再読込後に復元しません。

## 5. 保存データ

すべてブラウザの `localStorage` に保存します。アカウント同期はありません。

```ts
type Progress = {

```

```ts
type GuidedProgress = number[];
// 例: [1, 2, 7]
```

## 6. 視覚・操作の方針

通常版:

- 黒を基調に橙・赤・黄の攻撃的なレイド表現
- 得点、HP、コンボ、効果音、振動で即時報酬

誘導版:

- 黒を基調にシアン・緑の学習プロトコル表現
- 「敵を倒す」より「論理を獲得する」感覚

共通:

- 最大幅を抑えたスマートフォン中心のレイアウト
- safe area対応
- 問題画像はタップで拡大
- 長い数式はカード内で折り返すか、その数式領域だけスクロール
- モーダル表示中は背面スクロールを止める
- Escapeでモーダルを閉じる
- 効果音・振動が使えなくても学習は継続可能

## 7. 現在の既知の制約

- 収録年度は2025年度 問題2のみ
- 端末間同期なし
- ログインなし
- 通常版の進行途中は保存しない
- 誘導版の途中ステップは保存しない
- 問題データが通常版と誘導版で一部重複
- 自動UIテストは最小限で、主要フローは手動確認が必要

これらは未実装機能であり、バグとして勝手に別方式へ置き換えないでください。改善する場合は、既存保存データと2モードの思想を維持する設計から始めます。
